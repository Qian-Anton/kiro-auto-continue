# kiro-auto-continue

[English](README.md)

Kiro 的会话有时做到一半就停了：网断了、模型太忙、额度用完了，或者 Kiro 重启了。人要是在睡觉、不在电脑前，任务就一直停在那儿，等你回来。

kiro-auto-continue 在后台盯着 Kiro 的会话。哪个这样停了，它就替你发一条消息让 agent 接着做，消息里附上你原来的要求，agent 知道刚才在做什么。它是 Windows 上的一个小程序，Kiro 照常用，不用装插件，也不用重启。

## 能做什么

- 一轮断了（网络出错、模型太忙），让 agent 接着做。同一个会话接连断，最多续三回，每回前分别等 1、5、15 分钟。
- 你自己点了停止的，不管。
- Kiro 重启以后，把重启前正在跑的会话接上。
- 额度用完了不重试。等 Kiro 重启，或者别的会话又能正常跑完一轮（说明额度回来了），再接着做。
- 「做到完」模式（要用才开）：agent 不再停下来问要不要继续，一直做下去。
- 窗口里列着最近的会话和每个在干什么，可以直接点「续」「停」，下面写着它最近做了什么。
- 会话页上单独一栏显示 Kiro 报的额度（和 Kiro 状态栏上的数一样）：本月的、试用的各一条，注明 Kiro 是几点查的、过去多久了。
- 手机通知，还能在手机上给它发命令（企业微信，要用再设）。
- 有会话在跑的时候，电脑不会自己睡过去。

它只在键盘鼠标三分钟没人动时才打字，打完切回你原来看的签。输入框里你写了一半的话，它不碰。锁着屏也能用。

## 开始用

需要 Windows 10 或 11，以及 Kiro IDE（在 1.4.86 上测过）。

1. 从 [Releases](https://github.com/Qian-Anton/kiro-auto-continue/releases) 下载 `KiroAutoContinue.exe`，放在哪都行。
2. 双击打开。第一次打开时 Windows 可能提示「Windows 已保护你的电脑」，因为这个程序没有做签名：点「更多信息」，再点「仍要运行」。
3. 窗口开着，它就在看着 Kiro。关掉窗口，它还在右下角的托盘里接着看；要退出，右键托盘图标，点「退出」。

想开机就开着，在「设置」页打开「开机自动启动」。

它做的每件事都记在日志里，窗口里点「完整日志」就能看。设置和日志都放在 `%APPDATA%\KiroAutoContinue`，只存在这台电脑上。

## 做到完

在消息里任何地方写上 `【做到完】`（或 `[until-done]`）。agent 停下来问问题、问要不要做下一步时，它会让 agent 自己拿主意，接着做。agent 头一回说做完了，会让它对照你的要求再核对一遍。

agent 写出 `【完成】`、或者 `【卡住】` 加原因时就停；推满 30 回、或者连着三回推了 agent 都没干活，也会停。你自己发一条不带标记的消息，做到完也就结束了。

做完记得看 agent 最后的汇报：本来该你拿主意的事，是它替你定的。

## 手机上收通知

通知有两种发法，设一种就行：

- 下一节的企业微信机器人：配对以后，通知由这个机器人发给你，就在你给它发命令的那个对话里。
- 企业微信群的消息推送：通知发到那个群里。进群，右上角「…」→ 消息推送 → 添加，复制 webhook 地址，粘到窗口「手机」页的「收通知」里，点「发一条试试」。

两种都设了，通知由机器人发，不再发到群里。只有机器人被企业微信拒了（Bot ID 或 Secret 不对），才改发到群里。

会话需要你的时候（接连断了三回、额度用完、做到完卡住了），还有「做到完」的任务完成了，都会收到消息。每天早上 8 点还有一条过去 12 小时的小结。这三样在「手机」页都能单独关掉。

webhook 地址别给别人，拿到它的人都能往群里发消息。

## 在手机上发命令（企业微信）

1. 网页端企业微信管理后台 →「智能专区」→「智能机器人」，建一个 API 模式的机器人，连接方式选「长连接」，可见范围只选你自己，复制 Bot ID 和 Secret。
2. 填进窗口「手机」页的「在手机上发命令」，点「连接」。
3. 连上以后，那里会显示一个配对码。给机器人发「配对 码」，之后它只听你的。

然后给机器人发：

| 发 | 结果 |
|---|---|
| `状态` | 先是一行 Kiro 报的额度，再列出最近的会话，每个带编号。 |
| `续 2` | 2 号接着做。 |
| `停 2` | 2 号停下。 |
| `2 一段话` | 把这段话发给 2 号。2 号正忙的话先排着，这一轮做完再发，发进去了机器人告诉你。 |
| `清 2` | 撤掉排给 2 号、还没发的话。 |
| `新 项目名 一段话` | 在这个项目的 Kiro 窗口里开一个新会话，发这段话。只开着一个 Kiro 窗口时，可以不写项目名。 |
| `帮助` | 看这张表。 |

英文命令也认（`status`、`continue 2`、`stop 2`、`clear 2`、`new`、`help`），发语音也行。手机上的命令要往 Kiro 里打字时，它会等键盘鼠标 15 秒没人动。

Secret 别外传，机器人只让你自己看得见：能指挥这个机器人的人，就能让你电脑上的 agent 跑命令。

## 设置

「设置」页能改：开机自动启动、有会话在跑时不让电脑睡眠或休眠、键盘鼠标停下多久才打字、语言。

别的设置写在 `%APPDATA%\KiroAutoContinue\config.json` 里，只写要改的那一项，比如：

```json
{ "untilDone": { "maxPushes": 50 } }
```

改完把程序退出再打开。全部设置见 [docs/how-it-works.md](docs/how-it-works.md#all-settings)（英文）。

## 从脚本版（v0.2）换过来

先关掉脚本版（关掉 `start.cmd` 的窗口）。两个一起开，会抢着续同一个会话，企业微信的机器人也只认一条连接。

再趁新程序还没开，把脚本旁边的 `config.json` 和 `remote-allow.json` 拷进 `%APPDATA%\KiroAutoContinue`，webhook、机器人和配对就都接上了。不拷的话，在「手机」页重新填一次、重新配一次对也行。飞书的群推送新程序不支持了。

脚本版还留在 [v0.2](https://github.com/Qian-Anton/kiro-auto-continue/releases/tag/v0.2)。

## 限制

- 只能在 Windows 上用。
- 它靠的是 Kiro 现在聊天面板的样子，Kiro 一升级可能就不灵了。
- 要续的会话，签得开在 Kiro 里。
- 手机上的命令，要它开着、电脑醒着才收得到。
- 额度是照搬 Kiro 报的数。它每 5 秒看一次 Kiro 有没有新查过，可 Kiro 隔多久查一次由 Kiro 自己定（有时一两个小时），这个数和你实际还能用多少也不一定对得上。
